# Khronos Vulkan & OpenGL Registries

Khronos Group maintains the authoritative XML registries defining API types, enums, extensions, and commands for Vulkan and OpenGL.

## Features

- **vk.xml Registry**: Machine-readable specification from which headers, validation layers, and wrappers are synthesized.
- **Explicit Device Architecture**: Instances, Physical Devices, Logical Devices, and Command Buffers.
- **Cross-Platform**: Support for Windows (Win32), Wayland, X11, Android, and macOS/iOS (via MoltenVK).

## Loading Vulkan Registry

```typescript
import { StandardsLoader } from "yolo-standards";

const loader = new StandardsLoader();
const vk = await loader.loadVulkan();
console.log(`Commands registered: ${vk.commands.map(c => c.name).join(", ")}`);
```
