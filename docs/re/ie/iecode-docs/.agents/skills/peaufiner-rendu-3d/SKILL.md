# peaufiner-rendu-3d

Follow [IECODE scope and execution](../../references/workflow.md).

Capture the defect with model hash, pose, camera, resolution, lighting and backend. Choose a concrete stopping criterion; test one discriminating hypothesis, correct the smallest authorized cause, then recapture under comparable conditions and inspect a regression view.

Read [capture and diagnosis procedure](references/details.md) for the active defect. Examine images directly; dimensions or a successful exit are insufficient. Report observed differences separately from inferred causes. CPU/GPU silhouette checks do not certify game fidelity. Deliver candidate, before/after captures and reproduction parameters.
