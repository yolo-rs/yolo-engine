# creer-assets-3d

Follow [IECODE scope and execution](../../references/workflow.md).

Create the requested asset locally in Blender: silhouette → geometry → UV → materials → GLB. Preserve an editable `.blend`, source hashes and attribution. Reopen the export in the intended consumer and inspect it; readable GLB alone does not prove animation or fidelity.

Read [the creation procedure](references/details.md) and [local tool map](references/outils-locaux.md) for the active stage. When Blender is unavailable, deliver the useful local inspection and identify the missing validation. Use existing asset assembly/render skills for integration.
