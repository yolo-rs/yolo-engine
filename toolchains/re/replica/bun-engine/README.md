# Bun Engine Nintendo DS replica records

These four records were migrated from `bun-os/docs/bun-engine/replica/` as
historical design and reconnaissance input for the Nintendo DS / Inazuma Eleven
replica work. They are kept in their own directory because the repository-level
`replica/recon.md` describes a different product target.

The architecture and build log describe an earlier implementation plan. Treat
their paths, toolchain versions, and blocker notes as dated evidence; verify them
against the current crate and toolchain before using them as build instructions.
Do not place ROMs, firmware, extracted game assets, or other copyrighted inputs
in this directory.
